# 桌面对话与记忆分区

桌面端提供“新建对话”、对话选择框、“切换对话”和“重命名”。每个对话绑定独立 `memorySpaceId`，对话 ID 与存储 ID 分开。管理器显示当前分区名称；添加、查询、审核、清空及聊天撤回作用于请求所属分区。

## 存储与旧数据兼容

- `conversations.enc` 保存对话名称、稳定 ID、分区绑定和当前选择，使用独立的系统保护密钥。
- 系统加密不可用时，对话注册表只保留在内存中，不回退为明文文件；记忆与历史仍沿用各自已有的加密可用性限制。
- `sessions.enc` 保存所有对话历史，按对话 ID 分组。
- 新分区存放于 `<userData>/memory-spaces/<memorySpaceId>/`。传统记忆、捕获来源、提取结果、基础关系与归并、L1/L2、向量索引、澄清和反馈使用各分区自己的存储实例与文件。
- 原有 `default` 对话显示为“历史默认对话”，仍使用原目录，避免搬移、复制或丢失旧数据库。无法确定归属的旧事实不自动拆分。
- API 设置和助手名称是应用设置；记忆权限和提取设置按分区保存，新分区继承历史默认分区的初始设置。
- 模型/OCR 文件共用。UIE/NLI 推理进程共用，但记忆目录、审核状态、实体目录、任务和请求结果归属保持独立。

## 切换与后台工作

分区实例按需加载。每个实例在创建时捕获固定目录、对话 ID、仓库及运行时，切换只选择当前实例。原对话的流式回复和后台任务继续处理，不重新指向新分区。

聊天、记忆和历史 IPC 携带明确对话 ID；主进程只允许注册表中的 ID，不接受调用方提供的存储路径。事件携带来源对话 ID，前端仅把对应回复显示在所属对话。编辑、审核等操作期间切换暂时禁用，后台提取及聊天流式输出期间允许切换。

切换保存当前文本和图片草稿，恢复目标对话的草稿。每个对话最多一个流式发送；不同对话可独立发送。退出时等待各已加载分区的捕获任务写入，刷新会话和记忆，再释放共用模型。

第一版一段对话一个独立分区，不提供跨分区召回或共享绑定。多段对话共享分区需要进一步明确共享、删除和权限语义后接入。

## 验证

注册表测试覆盖旧目录兼容、独立存储路径、重启恢复、重命名、未知 ID、损坏绑定与持久化失败。

真实 Electron 测试使用独立临时目录和本机模拟 API，覆盖新建按钮、切换时仍在进行的回复/提取、相反传统偏好、同名样品的不同 L1 事实、历史隔离、重命名、重启及分区清空。未读取用户数据库或访问真实模型服务。L2 使用独立仓库实例和路径，其真实模型审核场景仍由已有专门测试覆盖。

本次全仓库测试：955 项通过、17 项跳过。桌面端类型检查与生产构建通过。
