## 本次新增验证

`open-recall-compatibility-regression.ts` 将实际抽取、发布、投影、审核与召回适配器串联，使用合成来源数据验证以下 5 项边界：

1. 自动开放导航不会产生正式聊天事实证据，也不会把同名提及合成同一实体。
2. 采纳开放断言不会自动发布 Claim 或 L2 关系；原生 L2 无需旧持久化配置。
3. 条件未解决的开放记录仍需显式候选查询，不能成为正式事实。
4. 拒绝审核或来源更新会使旧投影失效。
5. 上下文向量查询遵守用户隔离，且不授予审核状态。

该用例接入现有单进程回归入口，并提供 Vitest 包装。
