# 后台 L1 提取、API 语义复核与澄清

## 已实现的执行链路

1. 当前消息持久化后登记后台任务；聊天不等待提取或发布完成，也不等待全部捕获任务 flush。
2. 每轮开始固定历史信息可见范围。V3/V4 普通召回、正式图召回和原文召回分别保存可见集合；模型调用前重新验证活性与权限。新发布信息最早下一轮进入召回。
3. 远程开放提取进入语义工作流。API 判断提取是否忠实于原文、定义关系含义，区分同义、反向、上下位、相关及不确定。
4. 同义/反向归并要求信息无损、角色完整一一对应，并通过结构和类型检查。观察类型与规范类型不同：基础关系的实体观察标签不直接变成普适本体约束。原文与实体身份不随关系归并而改写。
5. 同词但含义不同或等价性未确认时保留独立义项。关系原始 ID、定义、模型判定、映射及撤销状态保存在加密仓储中。
6. 对代词或角色缺口先查找当前消息捕获时的近期用户上下文。只读取实际原文及其 ID/hash；截断过的上下文摘要和助手生成文本不能代替用户证据。
7. 仍无法解析时由 API 生成具体问题。问题绑定工作项、候选与来源版本；界面在当前流式回答完成后显示，正常聊天可继续。
8. 用户可以填写说明或选择已有消息。补充信息作为独立来源保存，再提取并复核；原文 text/span 保持原样。resolvedText 必须有补充证据，不自动合并不同来源中的同名实体。
9. 正式 Fact、Claim 和投影完整发布后才可正式图召回。补充引用、否定、计划、条件、时间和说话者信息跟随事实保存，并在提示词中与原始引用分开展示。
10. L2 使用完整原文、角色与语境进行比较；同名而引用不同的来源局部实体不能直接作为同一对象发布逻辑关系。L2 仍保留独立审核及时间、上下文和来源检查。

## 存储与状态

- 原文/任务仍使用原有 capture repository。
- 基础关系与可撤销映射：`graph-basic-relations.enc`。
- API 复核、待澄清、重试及模型/管线指纹：`graph-semantic-workflow.enc`。
- 已发布事实及所有证据继续使用 V4、L1 outbox 和 ready 投影。
- 工作流状态为 pending、processing、waiting、ready、published、failed、dismissed、cancelled。
- ready 表示审核完成，published 表示至少已有合格候选发布；不表示原始模型的每条输出都已成为事实。
- 调用或格式失败最多三个评审尝试；退出时的 processing 可恢复为 pending。显式新说明形成新评审输入。源撤回后忽略迟到响应。
- 模型、端点或提示词管线版本变化不复用旧配置评审。源版本变化使旧澄清失效。

## 界面操作

在开放关系优先或智能提取模式下使用 API 流程。UIE/规则离线入口不暗中增加远程调用。

回答后可能出现“补充记忆信息”卡片，可以稍后答、引用近期消息，或选择不保存该候选。忽略、超时与未回复都不视为批准。

失败项可点击“重试未完成的记忆整理”。记忆管理器提供“使用当前 API 处理历史开放记录（每批 5 条）”：从原文重新提取再复核，按来源版本去重，保留人工决定，检查当前发送权限。该操作是显式分批执行，不在启动时把历史原文全量发给 API。

撤销关系映射后，相应旧映射事实停止使用，并按独立关系重建。旧版本、人工决定与原文证据不会被模型归并直接覆盖。纠错修订和现实状态变化保持不同处理语义。

## 正式 L1 的表示

支持单参与者事件、多参与者关系及字面值。V4 的兼容 subject/object 是存储锚点；一元陈述的两个兼容锚点可引用同一实际参与者，但正式 Claim 只保留一个语义参数，不生成自循环业务边。完整参数以 sourceStatement 与 Claim 为准。

sourceStatement 保留关系表达/跨度、映射、参数和语境；补充证据分别进入 Episode、EvidenceLink 与 Claim provenance，不拼成假原文。基础注册不授予唯一性、传递性或其他规则能力。

## 验证与范围

自动化覆盖后台未完成时仍输出、每轮固定可见范围、原文/补充证据分离、计划模态、已有上下文解指代、缓存配置变化、同义与不同义、失败恢复、拒绝/撤销、重启、单/多参与者、正式召回和 L2 身份检查。

真实 API 评测使用当前配置的 deepseek-flash，全部输入为合成样例，没有发送用户历史。初轮六例包括存放、同义、暂存、否定、三参与者和指代歧义；五条明确记录发布，歧义记录暂缓。复测验证同义归并及澄清后正式发布。短样例的后台处理也耗时十几秒到一分钟以上，因此这些步骤不处于聊天等待链路。

这些样例用于验证实际 API 的链路和暴露错误，不代表所有领域或长文本的提取/合并准确率，也不等于现实真值认证。历史迁移能力已接入，但本轮没有替换用户已安装的发行版，也未自动迁移其实际历史数据库。
