# 实体局部宽候选与证据筛选

后续已安装真实本地交叉编码器并完成 G/H 对照。严格输出匹配提升到 20/29，但出现 3 个额外证据错误，尚未启用为桌面默认，见 [真实模型实验记录](local-cross-encoder-experiment.md)。下文保留宽候选阶段的实现说明。

## 本轮变化

实体向量仍先定位实体，再通过精确版本的实体—Claim 邻接索引定位局部事实。新的默认局部策略不再用 0.8 相似度提前丢弃候选，而是排序后保留最多 `candidateSelection.candidateLimit` 条（默认 64）。L1 直接事实和 L2 遍历起点均已接入。

宽候选与最终证据分开：未配置独立证据判断器时，最终输出仍用原始检索相似度的原有准入规则；重排分数不能替代它。保留 `entityClaimCandidates: 'threshold'` 可复现旧入口；默认 `'wide'`。整个变化仅针对实体定位后的局部事实，不增加全局事实检索回退，也不增加推导关系。

## 可替换的证据判断器

`candidateSelection.evidenceSelector` 是可信本地宿主注入的 `GraphEvidenceSelector`，与 `reranker` 分离：

- 重排器决定候选顺序，不决定能否回答。
- 判断器接收查询、候选原始分数及正文，返回 `accepted` 与所选 ID，或 `insufficient` / `ambiguous` 与空 ID 集合。
- `accepted` 只代表相关证据选择，不代表事实真值、逻辑证明或校准后的正确概率；命题原有极性、来源、有效时间等仍原样保留。
- 不能新增 ID、重复 ID；不充分/歧义不能夹带输出。超时、异常、非法结果均不输出候选，并在 trace 中记录原因。
- 判断器不能越过权限、时间、精确版本和来源检查。调用完成后，L1/L2 继续执行原有动态读取校验。
- 它可以从低于旧阈值的候选中选取证据，但必须显式配置；本轮未安装或默认启用任何新的判断模型。

判断与重排共用请求剩余预算，每个调用最多使用配置时间且不超过当时剩余预算的一半。真实模型可能需要重新评估时延预算，不应直接提高超时并宣称可上线。

Agent 提示词现在区分候选相关性歧义、证据不足和判断器不可用：歧义时可澄清，失败时不能推断“用户没有这条事实”。仅固定状态标签进入摘要，不把模型分数称为答案概率。

## 诊断与验证

新增 `candidate-pool` 阶段，记录截断后的宽候选，与最终 `selection` 分开。判断器耗时计入候选选择阶段总耗时；报告阶段时间不等于纯索引耗时。

统一真实模型入口 `eval/run-cross-topic-model.mjs` 保留 A–E 对照，并增加 F：实体局部宽候选＋保守输出筛选。报告 schema 为 `cross-topic-recall/v2`，新增“候选完整覆盖”统计，仅统计有非空预期答案且未刻意限制输出的 21 个问题。严格输出匹配仍使用原来的 29 个质量用例，两个分母不可混用。

2026-10-01，已安装本地 BGE 模型实测：

| 实体局部策略 | 候选池完整覆盖预期证据 | 最终证据集合完全匹配 | 边界检查 |
| --- | --- | --- | --- |
| E：原阈值入口 | 7/21 | 15/29 | 31/31 |
| F：宽候选＋保守输出 | 20/21 | 15/29 | 31/31 |

唯一未进入候选的有答案用例仍是周期时间表达导致的请求解析错误。其余候选覆盖缺口在该夹具中已补上；最终改写回答质量尚未因此改善。这是只有 2 个实体、11 个事实的合成测试，不能推广为大型实体库召回率，也不是生成答案正确率。

`wide-candidate-regression.ts` 用受控向量与模拟判断器验证布线：低分候选保留、未批准不输出、低分候选被显式选中后进入 L1/L2、拒绝陌生 ID、超时不输出、来源删除使结果失效。模拟判断器不用于宣称真实语义能力。

## 下一步

在保留 E/F 对照的基础上，接入真实、通用的本地相关性判断模型或现有可信模型适配器。用独立标注样例测试人物、否定、多答案、无答案和跨主题改写，再决定如何替换默认保守输出规则。同时单独修复周期时间查询；之后继续问题→关系方向规划和同层边语义排序。
