# 无 schema 信息入图

捕获源先写入加密的 `memory-captures.enc`，随后从其中仍处于 `active` 状态、且原文与附件哈希精确匹配的来源构建 `information` 节点。该过程不等待 UIE、规则提取或 V3 记忆审核；即使模型输出 `{}`，节点也可进入 `graph-semantic.enc` 和 `graph-l1-projection.enc`。节点保留完整原文、捕获源 ID、修订和哈希，并默认只允许本地查看。删除或替换捕获源会立刻使旧图视图不可读；下一次同步重建图并移除旧节点。

`information` 是来源记录，不是断言、V4 Fact 或 L1 Claim。它不进入 L2 NLI 端点，也不自动注入聊天回答或作为推理前提。仍能解析且经过审核的谓词关系继续形成带精确 V4 证据的 Claim。后续若要从开放信息做召回，应增加独立的来源引用与访问控制协议，而不能把开放文本伪装成已证实的 Claim。

桌面端“长期记忆管理”显示原文信息节点总数和最近 20 条的本地预览；这与“已审核 L1 Claim”分别计数。当前实现解决的是**不受谓词 schema 限制的入图与可追溯性**，不是无 schema 的自动事实审核或逻辑推理。
