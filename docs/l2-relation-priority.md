# L2 合格关系的局部语义排序

本轮承接问题类型/方向规划，增加有界的关系排序。输入端的关系发布、审核和数据库格式不变；
只消费已通过固定视图检查的正式关系和精确版本端点。本轮不对接新的基础关系发布接口。

## 读取与遍历顺序

1. 沿用 L1 候选入口及起点选择，按问题明确关系类型、方向和时间约束。
2. 从当前节点的邻接索引读取一页合格边。启用排序时默认每页 4 条，配置上限 16。
   底层权限、时间、来源、端点和版本检查不变，读取继续消耗同一个召回预算。
3. 回读关系记录、两端事实文本和来源，核对边与权威记录一致后，才把这一页交给排序器。
4. 在这一页内排序，依次记录路径、将尚未访问的端点加入 BFS 队列。保留全部合格边，
   去环、最短前驱路径、每个起点独立的访问记录、最大跳数和竞争原因覆盖检查继续生效。
5. 分页游标仍属于原读取顺序，不因语义顺序而修改；返回前再次检查全部证据权限与有效性。

这是**同一节点的一页邻居之间排序**，不是全图排序，也不是整层所有父节点的联合排序。
先完成当前节点的分页，再扩展队列中的节点；后一页更相关的边不会提前到前一页。
它调整的是已取得合格关系的探索优先级，不保证已经取得全局最相关关系。

## 当前评分内容

`relation-priority.ts` 提供可替换的本地 `GraphRelationRanker`。首版使用已有事实向量缓存：

```text
priority = (cosine(完整问题, from 事实文本) + cosine(完整问题, to 事实文本)) / 2
```

查询使用完整问题，种子检索仍使用规划器提取的目标文本。每次召回内复用完整问题的向量，
不会为每条关系重新调用模型，不新增关系向量数据库。缓存按事实 ID、模型及精确文本读取；
同页同事实 ID 出现不同版本或文本时不排序。同分保持原页顺序。

**关系类型、方向、身份、语境和时间作为硬约束，未混成语义分数。**
当前未单独编码关系说明或语境文本；后续可替换排序器，但不能靠评分改变关系语义。
余弦值只决定顺序，没有“正确概率”含义，也没有低分裁剪阈值；
不能将 `explains` 改成 `causes`，不能倒置关系，更不能自动采纳未发布关系。

## 回退、预算和覆盖

- 任一端点缺少可用向量、向量维度/模型不符、排序失败或返回非法引用时，整页保留原顺序。
  不把未生成向量的竞争解释系统性排到末尾。
- 每页排序等待至多 200ms，同时不超过剩余召回时间的一半；超时后丢弃迟到结果。
  本地模型底层计算可能仍会结束，但不会回写迟到的召回结果。
- 只有 0/1 条关系时不需要评分；显式 ID 召回没有自然语言问题时保持原顺序。
- 先核对和装配再排序会提前读取一个窗口的证据，这部分节点、来源、时间成本不会免除。
  排序并非无成本加速，可能增加耗时；效果与开销需要后续对照实验验证。
- 不因语义分数低删除矛盾边或竞争解释；仍受原先类型、方向和预算范围限制。
  未提供全面冲突审计，不能声称已排除全部冲突。
- 底层保留截断状态和已完成证据组。桌面宿主仍拒绝预算耗尽的结果，不会把部分遍历包装成完整答案。
  因此本轮不能宣称已提高预算耗尽时的可回答率。

## 配置和诊断

通用 `createV4L2Memory` 仅在显式配置 `relationPriority`、本地语义模型可用且入口非 `lexical` 时启用。
桌面图记忆路径在这些条件下默认启用窗口 4、超时 200ms。普通聊天是否启用图记忆仍由原有开关控制。

启动时设置 `CONTINUUM_GRAPH_RELATION_ORDER=source` 可恢复原始关系读取顺序（逐条读取）。
关键词基线始终不使用关系向量排序。比较 L1 关键词/向量/混合入口时，应对所有方案显式使用
`source`，先隔离 L1 入口效果；随后保持 L1 入口一致，再对照关系排序开关。
这个开关同时改变读取窗口；若只研究评分对顺序的影响，低层可配置相同窗口的恒定分数排序器。

底层 `relationOrdering` 记录窗口所在起点、节点、深度、排序后的精确关系引用、状态和耗时。
桌面 trace 与 `relation-ordering` 诊断事件汇总窗口数、启用次数、原顺序回退次数和排序耗时，
不输出向量或原文。`applied` 代表成功评分，不代表顺序一定改变或答案已充分。
Agent 提示明确“局部优先级不等于答案置信度，未探索边可能更相关”。

## 本轮验证与下一步

按当前要求只做 memory、core 和桌面主进程 TypeScript 静态检查与差异检查；
不运行回归、模型测评或桌面程序。运行时正确性、预算边界、质量与延迟变化尚待验证。
下一步继续完善证据可回答性：区分直接事实、关系证据、多个解释与证据不足，
不把向量分数当作输出答案的概率阈值。
