# 桌面聊天与阅读功能

## 入口

- 左侧底部“设置”：聊天字号、行距、阅读宽度、快捷键和发送按键。修改阅读设置可预览，点击“保存设置”后重启仍保留；取消会恢复原设置。
- 顶部“API 已配置 / 配置 API”：独立的 API 配置入口。
- 左侧“搜索对话”：查找已有聊天记录的标题与正文。点击结果跳到命中的消息。
- 消息下方：复制、引用和收藏。选中消息片段后点击复制或引用，操作选中的片段；代码块有独立的复制按钮。
- 左侧“收藏”：回看收藏全文并返回原文。原文移出近期聊天记录后，收藏全文仍保留。
- 历史对话标题旁的归档图标：打开归档列表。顶部更多菜单可以归档或恢复当前对话；归档保留历史与原记忆分区。
- 输入框工具栏：展开输入框和快捷短语。小窗口下识屏与语音放入“更多输入方式”。
- 顶部记忆状态按钮：查看等待、处理中、待补充、失败与 L1 发布数量。整理完成不会被标记成 L1 已发布。
- 顶部更多菜单：导出当前对话为 Markdown 或 TXT。

## 默认快捷键

- `Ctrl + N`：新建对话。
- `Ctrl + L`：聚焦输入框。
- `Ctrl + K`：打开对话搜索。
- `Enter`：发送；`Shift + Enter`：换行。可以在设置中改成 `Ctrl + Enter` 发送、`Enter` 换行。
- 展开的编辑区使用 `Enter` 换行、`Esc` 收起，内容和选区位置会保留。

## 回复、草稿与记忆

生成中点击停止按钮会中止模型请求，保留已输出内容。停止不会撤销已经执行的工具操作；当前工具结束后不会再启动后续工具调用。

最近一次失败或停止的回答可以点击“重试”。持久化的用户消息会被复用，避免再次提取同一条输入。仅存在于本次运行缓存中的图片在重启后需要重新附上。

草稿按对话分别保存，包含文字、引用与所选 Skill；关闭窗口前会同步保存未完成的草稿。未发送的图片仍是本次运行的缓存。

引用保留原消息归属和片段；本轮新输入与引用分开进入运行时，引用不会被当作本轮新的用户事实。收藏是独立的消息副本，不会自动进入 L1。

草稿、快捷短语、阅读设置及收藏使用系统保护的加密文件。收藏全文单独保存，避免每次输入都重写全部收藏。

## 验证

针对性测试覆盖设置迁移、草稿恢复、收藏全文、归档保留分区、中文正文搜索、引用校验、Markdown 渲染与导出，以及真实本地 SSE 请求中止、重试不重复提取输入。

隔离的 Electron 界面检查覆盖两批十四项功能、关闭并重新打开恢复，以及六种主题的 75%–200% 缩放。验证使用示例对话与本机模拟模型，不调用收费模型 API。
