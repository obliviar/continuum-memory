# 独立原文捕获与任务记录

## 已实现的边界

聊天捕获入口保持不变。Electron 启用长期记忆时，先将原文和全部分段任务一起写入独立的 `memory-captures.enc`，保存成功后才执行抽取。密钥由系统 `safeStorage` 保护，文件位于应用 `userData` 目录，与事实库、V4 影子库分离。没有候选、审核未通过、模型失败都不再导致原文丢失。原文不加入向量索引，不作为已审核记忆参与召回。

此步骤只建立输入证据与任务基础设施，没有新增 L1 实体边、L2 逻辑边，也不会根据路径生成新记忆。

## 数据结构

- `CaptureSource`：独立 source ID、隔离 scope、消息 ID、源身份、修订号、内容摘要、创建时间、状态和原始捕获输入。状态为 active / superseded / deleted。同一消息编辑后生成新修订，旧任务失效；上下文、图片附件一并加密保存，以便重放，均不是事实证据。
- 来源身份中的会话 ID 用于重复投递识别；`writeScope` 保存调用方原本的记忆隔离范围。桌面端的跨会话记忆写入不因来源属于某个聊天会话而变成仅限该会话的事实。
- `CaptureTask`：任务 ID、source ID、抽取配置版本、分段序号/总数、原文 `[start,end)`、`utf16` 坐标约定、`identity-v1` 预处理版本、状态、尝试次数、时间、候选数、写入数、稳定错误码。原文不做 NFKC、空白合并或静默裁剪，分段不截断代理对。UIE 若输出 Unicode code-point 坐标，后续需先转为分段内 UTF-16，再加 `start`，不能直接相加。
- `CaptureStatus`：不含原文的统计信息，通过 `memory:status`、`memory:list` 返回，并显示在记忆管理面板。

任务状态：pending → running → succeeded / failed；来源删除或修订失效 → cancelled。`succeeded` 且 `candidateCount=0` 表示正常空结果，不等于失败。`writtenCount` 只统计当前执行写入的事实，不包含待审核候选。

## 重启、幂等和重试

启动时将中断的 running 恢复为 pending；等待 V4 初始化完成后恢复当前抽取配置匹配的待执行任务。失败任务由用户在面板主动重试，每项最多尝试 3 次（包括被中断的执行）。配置不匹配的任务保留并显示为等待原配置，不能悄悄切换模型或远程策略执行。

消息身份使用 owner / agent / session 和来源消息 ID；同一消息、相同文本和附件重复投递复用任务。没有来源消息 ID 时可提供稳定 `metadata.memoryCaptureId`，否则每次调用视为独立来源，并分配合成证据 ID。相同文本的不同消息不被误合并为同一来源。已成功任务不重放；重复提交失败任务也不会隐式重试。

原文与任务在同一快照内原子保存，但事实库和任务库之间没有跨库事务：执行语义是 **at-least-once**，进程在事实写入后、任务完成前崩溃时，恢复可能再次执行。事实层沿用已有内容/来源去重；这不是 exactly-once 保证。候选审核观察者的失败仍沿用现有隔离策略，不将任务标记为失败；UIE / smart / OCR 内部回退到规则也仍属于现有抽取流水线行为，任务成功不保证指定模型成功运行。独立模型步骤状态和原始 UIE 结构化输出持久化留给后续抽取阶段。

`flushPendingCaptures()` 覆盖前台首段、后台分段和已调度恢复任务；`resumePendingCaptures(true)` 对匹配配置且未超次数的失败任务进行显式重试。`captureSnapshot()` 是主进程/后端诊断接口，包含敏感原文，不应直接通过 IPC 暴露。

## 删除与限制

- 删除聊天来源时立即取消关联任务并抹除原文、上下文、附件，再等待已运行写入退出并同步事实来源。引用被删消息作为上下文的捕获也保守取消，避免重放已删除文本。
- 清空记忆同时清空该 scope 的捕获原文，保留不含原文的取消任务记录。彻底清除事实时，关联捕获来源也抹除，并清理应用管理的备份。软删除事实不删除原始证据。
- 单条原文最多 100000 UTF-16 单元，完整捕获输入最多 16 MiB，超限显式报错而非截断。原文快照采用全量加密写入，当前适合桌面单进程、单仓库实例；尚无自动保留期清理和多进程租约，不可把同一个仓库同时交给多个 worker。
- 更换抽取协议时需更换 `captureProcessorVersion`。桌面配置指纹涵盖模式、远程策略、图片开关、UIE 路径和 API 模型/地址；不包含 API 密钥，不替代模型权重内容校验。
- 没有对历史聊天自动回填；仅捕获新进入该流程的消息。原始输入比候选记忆包含更多敏感信息，应使用“删除来源 / 清空记忆”管理其生命周期。
